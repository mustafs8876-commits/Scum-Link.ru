# Отличия от видеореференса

1. Опасные инструкции по краже/использованию токенов заменены нейтральным демо-текстом.
2. Реальные банковские реквизиты из видео заменены на `0000 0000 0000 0000 / DEMO USER / DEMO BANK`.
3. Кнопки Telegram и внешние CTA не открывают внешние адреса.
4. Активация ключа — только UI-состояние и локальное уведомление.
5. Исходные изображения/видео из старого проекта не были предоставлены отдельными файлами, поэтому созданы нейтральные SVG-заглушки, близкие по размерам и тональности.
6. Мобильная версия восстановлена по desktop-референсу с профессиональной адаптивной логикой, так как отдельного мобильного видео не было.
